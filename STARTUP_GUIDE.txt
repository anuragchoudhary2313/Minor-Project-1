📋 GoFood Startup Instructions
================================

CRITICAL: Backend must be running BEFORE frontend can work.

OPTION 1: PowerShell (Recommended - shows output)
=========================================
1. Press Windows Key + R
2. Type: powershell
3. Paste this command:

cd "c:\Users\anura\OneDrive\Desktop\projects\FoGood\Gofood\backend"; node index.js

4. Wait for this message:
   ✅ MongoDB Connected...  OR  ⚠️ MongoDB Connection Failed: Using mock/fallback data...
   🚀 Server running on http://localhost:5000

5. Leave this window OPEN
6. Open another terminal to start frontend

---

OPTION 2: Using the bat file
=============================
1. Navigate to: c:\Users\anura\OneDrive\Desktop\projects\FoGood\
2. Double-click: start-backend.bat
3. Window should show "Backend exited. Check MongoDB connection..."
   If you see: "🚀 Server running on http://localhost:5000"
   Then SUCCESS - minimize the window (keep it open)

---

OPTION 3: Command Prompt (CMD)
==============================
1. Press Windows Key + R  
2. Type: cmd
3. Paste:

cd /d "c:\Users\anura\OneDrive\Desktop\projects\FoGood\Gofood\backend" && node index.js

---

FRONTEND (in a DIFFERENT terminal):
===================================
1. While backend is running, open NEW terminal
2. cd c:\Users\anura\OneDrive\Desktop\projects\FoGood\Gofood
3. npm start
4. Browser should open at http://localhost:3000

---

If you see "Port 5000 is in use":
================================
Backend may already be running on different port. Fresh browser (Ctrl+F5) and frontend 
should auto-discover it. OR close other terminals and try again.

If MongoDB error persists:
===========================
That's OK - using mock test data. All features work including search/cart/menu.
